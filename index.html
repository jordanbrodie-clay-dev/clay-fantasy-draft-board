How this was built

By Jordan Brodie · built with Clay

This board isn't a rankings list I copied. It's a model sitting on top of a dataset I generated myself using Clay workflows, authored from the command line with the Clay CLI. Every number traces back to a source.

Workflows→ Structured data→ Qualitative signal→ Player quality→ Market + roster optimizer→ Smart pick
1Author workflows from the CLI

Used the Clay CLI to create multi-node workflows programmatically instead of clicking through a UI. Three workflows: player research, team environment, and coach sentiment.

2Pull structured data via API

Each workflow chains search → scrape → structured extraction, returning typed JSON with a source URL for every value. 200 players enriched with 2025 usage, efficiency, Vegas props, and injury history. A second workflow built all 32 team environments: Vegas win totals, offensive line ranks, coaching changes, and vacated carries and targets.

3Add qualitative signal

A third workflow reads player news, beat reporting, and direct coach quotes, then grades role language. Critically it separates concrete role statements ("he'll be our starter", "first-team reps") from generic August coachspeak ("he's looked great") — only the specific kind is allowed to move a score. Generic praise is flagged and scored zero.

4Draft BPA intelligently

Smart rank blends Sleeper, ECR, and a 1.5× Winks anchor. The simulator begins with the highest-ranked available player, then checks acquisition windows and the projected positional cliff. A strategy pick can pass BPA only within three rank spots and only with a material scarcity advantage. Early RB/WR depth remains valuable, so the engine supports BPA-heavy starts instead of forcing a tidy starting lineup.

How it was refined

  • Calibrated on five completed seasons of real preseason ADP and outcomes (2020 through 2024; 851 matched player-seasons). Historical pick dispersion tunes future availability, and position-by-round starter hit rates are shown in every player detail.
  • Added weekly game logs to compute with-and-without splits: how a player performed in the specific games a teammate missed. 116 such teammate pairs, which is how contingency and handcuff value became measurable.
  • Modeled same-team competition for touches, so a crowded backfield or receiver room is priced rather than assumed away.
  • Added spike-week ceiling data after testing showed spike magnitude predicts future value while spike frequency is already priced in by the market.
  • Every row carries a confidence grade from A to D based on how much verified data actually supports it, so a well-sourced rank and a thin one don't look identical.
  • Kickers and defenses use Sleeper ADP with a late-round defer rule. They complete the roster model without pretending those volatile positions deserve the same research spend as RB, WR, QB, and TE.
